# Industrial Order Management App

Desktop application for managing industrial orders, customer information, product dimensions, and weight-related calculations.

## Overview
This project is a Windows desktop application designed to help record and manage industrial product orders. It stores customer and contract information, product dimensions, and order-related values in a local SQLite database.

## Features
- Register and manage orders
- Store customer and contract information
- Save product dimensions and specifications
- Track standard and optimized weights
- Use local SQLite database for data storage

## Tech Stack
- Python
- Tkinter
- SQLite
- PyInstaller

## Project Files
- `main_app.exe` — Windows executable version of the application
- `orders.db` — SQLite database file used by the application

## How to Run
1. Download the project files or the latest release.
2. Make sure `main_app.exe` and `orders.db` stay in the same folder.
3. Run `main_app.exe` on Windows.
